# v0.23.0-beta 日本語歌詞アドオン
このアドオンはユーザー提供の Sing 対応 spoti.pw 0.23.0-beta / Spotify 9.1.78 用です。
本体の spotifyglass.dylib を変更せず、独立した SGJapaneseLyrics.dylib を追加します。

## 操作
- 翻訳アイコンをタップ: 日本語に翻訳。曲ごとの確認・選択メニューはありません。
- 翻訳アイコンを長押し: 自動翻訳、表示、文字サイズ、API設定。
- 歌詞の行を長押し: その行と前後2行から意味・比喩・スラング・ライムをAI解説。
- 元の注釈がある行: 解説シートの「出典の注釈」から元の注釈にも移動できます。
- iOS 26以降の追加ボタンはネイティブLiquid Glass。以前のOSは塗りつぶし。

## 自動翻訳
初期状態はオン。保存済みAPIキーがあり、歌詞が表示され、アプリが前面にある時だけ実行します。
日本語のかなを含む行または日本語と推定される行が1行でもあれば、その曲は自動送信しません。
日英混在も保守的にスキップします。文字が少ない歌詞・言語不明・低信頼度もスキップします。
手動翻訳では日本語と判定した行をそのまま残します。言語の自動判定は完全ではありません。
失敗時に自動再試行を繰り返しません。アイコンをタップして手動で再試行できます。

## 表示
「原文＋日本語」「日本語だけ」「原文だけ」、文字サイズ24/30/36/42ptを保存します。
「日本語だけ」は全ての非空行に訳がある場合だけ適用し、欠けている場合は原文も表示します。
日本語の曲を自動で訳すことはなく、訳がない行は原文が残ります。
「原文だけ」では自動翻訳の通信も行いません。元の単語・再生タイミングは変更しません。
日本語だけの表示では、原文の単語ごとのハイライトは表示しません。

## AI解説
APIキーは翻訳と共通。選択した行＋前後2行をGoogleへ送信します。
外部資料・音源の照合は行いません。「AIによる解釈」と明記し、意味/スラング/韻/不確かな点を分けます。
作者の意図、実際の発音、公式な解釈を検証した結果ではありません。
解説はセッション中のメモリキャッシュ最大100件。翻訳はローカルキャッシュ最大50件。
APIキーはKeychainに保存し、GitHubへ送信しません。API料金・上限はGoogle側設定に従います。
APIの出力内容を実環境で確認するにはユーザー自身のキーと実機が必要です。

## 検証とビルド
GitHub Actionsの専用ブランチでパッケージングのPythonテスト、
macOSのNaturalLanguageによる言語ポリシーテスト、iOS向けclang警告エラー有効ビルド、
アドホック署名検証を実行します。実機のUI・API通信は別途確認が必要です。
Mac/Xcodeで bash build.sh。Windowsでは次の例で元のIPAに組み込みます。

    py -3 inject_translation.py --ipa "sing enabled 23.0 beta.ipa" --dylib "build/SGJapaneseLyrics.dylib" --output "Spoti_023Beta_JapaneseLyrics_Enhanced.ipa"

元IPAは固定SHA-256で検証します。SideStoreで再署名してインストールしてください。

再起動後、リデザインの歌詞画面で外国語曲の自動翻訳、日本語曲のスキップ、
アイコン長押しの表示/サイズ変更、歌詞長押しのAI解説を確認してください。
