# v0.23.0-beta 日本語歌詞アドオン
このアドオンはユーザー提供の Sing 対応 spoti.pw 0.23.0-beta / Spotify 9.1.78 用です。
本体の spotifyglass.dylib を変更せず、独立した SGJapaneseLyrics.dylib を追加します。

## 操作
- 翻訳アイコンをタップ: 日本語に翻訳。曲ごとの確認・選択メニューはありません。
- 翻訳アイコンを長押し: 自動翻訳、表示、文字サイズ、API設定。
- 歌詞の行を長押し: その行と前後2行から意味・比喩・スラング・ライムをAI解説。
- 元の注釈がある行: 解説シートの「出典の注釈」から元の注釈にも移動できます。
- iOS 26以降の追加ボタンはネイティブLiquid Glass。以前のOSは塗りつぶし。

## 自動翻訳
初期状態はオン。保存済みAPIキーがあり、歌詞が表示され、アプリが前面にある時だけ実行します。
日本語のかなを含む行または日本語と推定される行が1行でもあれば、その曲は自動送信しません。
日英混在も保守的にスキップします。文字が少ない歌詞・言語不明・低信頼度もスキップします。
手動翻訳では日本語と判定した行をそのまま残します。言語の自動判定は完全ではありません。
失敗時に自動再試行を繰り返しません。アイコンをタップして手動で再試行できます。

## 表示
「原文＋日本語」「日本語だけ」「原文だけ」、文字サイズ24/30/36/42ptを保存します。
「日本語だけ」は全ての非空行に訳がある場合だけ適用し、欠けている場合は原文も表示します。
日本語の曲を自動で訳すことはなく、訳がない行は原文が残ります。
「原文だけ」では自動翻訳の通信も行いません。元の単語・再生タイミングは変更しません。
日本語だけの表示では、原文の単語ごとのハイライトは表示しません。

## AI解説（検索対応版）
APIキーは翻訳と共通です。標準モデルはgemini-3.8-flashで、ユーザー設定を優先します。
解説画面には設定モデル、応答後にはAPIが返した実際のモデル名を表示します。
曲名・アーティスト名・選択行と前後2行をGoogleへ送り、google_searchを有効にします。
本人/レーベルの発言、音楽記事、辞書、Geniusなどを調べるよう指示しますが、個別サイトへのアクセスや検索成功は保証されません。
曲情報は対象トラックIDに対応するSGKaraokeTrackForと、確認済みtrackTitle/artistNameセレクタだけから読みます。
未取得の場合は歌手や曲を推測せず、語句自体の説明に限定するよう指示します。
外部資料に記載された内容、AIによる解釈、不明点を区別するよう指示します。
音源・実際の発音を分析していません。ライムの音声上の一致は仮説です。
本文の引用リンクはgroundingSupportsとgroundingChunksから生成し、モデルが本文に書いたURLを自動リンクにしません。
引用オフセットはPartごとのUTF-8バイトからNSStringのUTF-16位置へ変換し、不正な参照を拒否します。
検索クエリ・有効なHTTPS出典・対応する引用箇所・Google検索候補HTMLがそろわない場合は、調査済みの解説として表示しません。
引用リンクがあるだけで、その出典が全ての解釈を裏付けるとは保証されません。
Google提供の検索候補HTMLを、非永続・JavaScript無効のWKWebViewに表示します。
検索結果は再利用用キャッシュへ保存しません。HTTPキャッシュなしの専用セッションを使います。
再表示や右上の更新ボタンは新しいAPIリクエストです。検索/APIの利用料金が発生する場合があります。
翻訳のみ既存のローカルキャッシュ最大50件を維持します。
APIキーはKeychainに保存し、GitHubへ送信しません。API料金・上限はGoogle側設定に従います。
APIの出力内容を実環境で確認するにはユーザー自身のキーと実機が必要です。

## 検証とビルド
GitHub Actionsの専用ブランチでパッケージングのPythonテスト、
macOSのNaturalLanguageによる言語ポリシーテスト、iOS向けclang警告エラー有効ビルド、
アドホック署名検証を実行します。実機のUI・API通信は別途確認が必要です。
Mac/Xcodeで bash build.sh。Windowsでは次の例で元のIPAに組み込みます。

    py -3 inject_translation.py --ipa "sing enabled 23.0 beta.ipa" --dylib "build/SGJapaneseLyrics.dylib" --output "Spoti_023Beta_JapaneseLyrics_Enhanced.ipa"

元IPAは固定SHA-256で検証します。SideStoreで再署名してインストールしてください。

APIキーは取得していないため実APIの検索結果とiOSの画面・外部リンクは実機未確認です。

## 最適化版の変更と検証範囲
- 翻訳キャッシュの読み書き・JSONデコード・古いファイルの整理を専用直列キューへ移動。
- メモリキャッシュは50件/8MiB目安。キャッシュなしも記憶し、画面更新のたびに同じファイルを読まない。
- 翻訳の重複適用を防止。適用済みの行配列自体も照合し、同じ曲の歌詞が再取得された時は正しく再適用。
- 自動翻訳の言語判定と手動翻訳の事前判定を背景キューへ移動。語句ごとの判定と正規表現を再利用。
- キャッシュからの復元後、APIキーがなくても保存済みの訳を使える。曲変更後の古い翻訳エラーを表示しない。
- 検索用WKWebViewは候補HTMLが届くまで生成しない。検索結果の保存・再利用は行わない。
- 不正・巨大なキャッシュを拒否し、キャッシュ整理は管理対象のJSONだけに限定。
実機のフレームレート・入力遅延・消費電力は未測定で、改善率やSpotify本体全体の不具合修正は保証しない。
確認：SideStoreで上書きして再起動し、リデザインの歌詞で曲切替・スクロール・同じ曲の再表示・長押し解説を試してください。
